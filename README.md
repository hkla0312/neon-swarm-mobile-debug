# NEON SWARM: SKYLINE SIEGE

スマートフォン向け公開デモ: `https://hkla0312.github.io/neon-swarm-mobile-debug/`

縦持ちスマートフォン向けのオリジナル3Dリアルタイムレーンバトルです。ワープゲート型召喚装置から選択中のユニットを1体ずつ投入し、プレイごとに配置が変わる倍率ゲートと障害物を攻略しながら、敵拠点が継続生成する小隊との戦線を押し返します。各ユニットは独立して索敵、追跡、障害物回避、HP制近接戦闘、再索敵、拠点攻撃を行います。外部画像・音声・3Dモデルは使用せず、表示物はThree.jsプリミティブ、BGM・効果音・ジングルはWeb Audio APIで生成します。

## 必要環境

- Windows 10 / 11（バッチファイル利用時）
- Node.js 22 LTS 推奨（Node.js 20.19以上でも動作）
- npm 10以上
- WebGL対応の現行版 Chrome / Edge / Firefox / Safari
- 初回の `npm install` にのみインターネット接続が必要です。ゲーム自体にバックエンドはありません。

HTMLの直接ダブルクリック起動には対応しません。必ずローカルHTTPサーバーを使用してください。

## ZIP展開後の初回セットアップと起動

1. `game-source.zip` を任意の書き込み可能なフォルダへ展開します。
2. `start-local.bat` をダブルクリックします。
3. 初回のみ依存関係を自動インストールします。
4. 開発サーバーの準備完了後、`http://localhost:53173/` がブラウザで開きます。
5. 終了時はバッチ画面で `Ctrl + C` を押します。

コマンドで起動する場合:

```powershell
npm install
npm run dev
```

同じWi-Fi内のスマートフォンで確認する場合は、Viteが表示した `Network` URL（例: `http://192.168.x.x:53173/`）を開きます。Windowsファイアウォールの許可が必要な場合があります。

## 操作方法

### スマートフォン

- 左右ドラッグ: 召喚装置を移動し、兵士の投入レーンを選択
- 通常兵は約1.2秒ごとに1体ずつ自動召喚
- 召喚後の索敵、移動、追跡、戦闘は自動
- ページスクロール、ピンチ拡大はゲーム領域で抑止
- 対応端末では重要な衝突時に短く振動
- 設定の「左右操作を反転」でドラッグ方向を反転

### PC

- マウス左右ドラッグ: 召喚装置を移動
- `A` / `D` または左右矢印: 召喚装置を移動
- `Esc`: 一時停止 / 再開
- `Space`: タイトル決定、作戦開始、リトライ
- 設定の「左右操作を反転」はキーボードにも適用

## ゲーム構成

- Stage 1 `GLASS FRONT`: ランダムゲートと少数障害物の入門戦
- Stage 2 `SHIFT PRESSURE`: 障害物と中型編成
- Stage 3 `CRIMSON COMMAND`: 移動ゲート、中ボス、敵拠点砲撃
- Stage 4 `VIOLET MAZE`: 高密度障害物と短い敵出現間隔
- Stage 5 `OMEGA CITADEL`: 大ボスが繰り返し出現する最終攻城戦
- ゲートの横位置、前後位置、倍率、移動有無はステージ開始ごとに再抽選。障害物と重なる候補は除外
- 障害物も毎回ランダム配置され、味方・敵とも回避しながら進軍
- 敵はノーマル / 中型 / 中ボス / 大ボスの4階級。階級ごとに体格、配色、発光バイザー、クレスト、コア装飾が変化
- クリア報酬で召喚速度、ユニットHP、攻撃力、召喚装置HP、開始時援軍を強化
- コインで人型ロボット、ビークル型、動物型を購入し、出撃時は所持ユニットから1種類だけを選択
- 味方3種はHP、攻撃力、攻撃間隔、移動速度、索敵範囲、攻撃範囲に固有の初期値を持つ
- 敵撃破でノーマル1、中型3、中ボス10、大ボス25コインを即時獲得
- 敵拠点破壊でステージ報酬と残存召喚装置HP分のコインを獲得
- 取得時は戦場に3Dコインが飛び出し、HUDの所持数更新、ポップアップ、専用取得音で通知
- 敵拠点のHPをゼロにすると勝利、召喚装置のHPをゼロにされると敗北
- 味方が全滅しても召喚装置が残っていれば継続召喚で立て直せます
- 兵士は移動中に腕脚を交互に振り、近接攻撃時は対象方向へ両腕を振り下ろします。被弾時は白くフラッシュして短くのけぞります。
- タイトル用・ゲーム中用はメロディと低音を組み合わせた複数小節のループBGMです。クリア時は専用ジングルへ切り替わります。ブラウザの音声制限により最初の操作後に再生を開始します。

## プロダクションビルド

`build-production.bat` を実行すると、依存関係確認、TypeScript型チェック、Viteビルドを順に実行し、`dist` を生成します。コマンドでは次の通りです。

```powershell
npm run typecheck
npm run build
```

ビルド済みデータは `preview-build.bat`、または次のコマンドで確認します。URLは `http://localhost:54173/` です。

```powershell
npm run preview
```

`game-build.zip` は `dist` の中身だけを収録します。展開先を静的HTTPサーバーで配信してください。直接ダブルクリックによる起動は保証しません。

## デバッグ

ブラウザで `F12` を押して開発者ツールを開きます。Consoleで例外、Networkで読込失敗、Performanceでフレーム時間を確認できます。モバイル表示は Chrome / Edge のデバイスツールバー（`Ctrl + Shift + M`）を利用します。

ゲーム画面で `F2`、またはバッククォートキーを押すと隠し `DEV BATTLE LAB` が開きます。

- FPS、味方数、敵数、戦闘中ユニット数の表示
- 味方召喚間隔、敵出現間隔の増減
- 新規ユニットの味方・敵HP / 攻撃力倍率変更
- 索敵範囲、攻撃範囲、ターゲット線の可視化
- 敵ウェーブの即時発生
- 召喚装置と敵要塞のHP変更
- ゲーム速度0.5倍 / 1倍 / 2倍
- 現在ステージの再読み込み
- 次ステージへ移動
- 勝利 / 敗北状態を発生
- 500コイン追加
- 保存データ初期化

## 保存データ

ブラウザのlocalStorageにキー `neonSwarmSave` で保存します。内容は所持コイン、クリア状況、ハイスコア、5種類の強化、購入済み・選択中ユニット、BGM/効果音音量、振動、左右操作反転、画質です。設定画面の「保存データ初期化」またはDEV BATTLE LABから初期化できます。旧版保存データは新しい保存形式へ移行し、破損・欠損値は安全な初期値へ戻ります。

描画品質は設定画面で「自動 / 低 / 高」を選択します。「自動」はCPU論理コア数を目安にピクセル比と影を調整し、レンダラーのピクセル比は最大2に制限します。

## よくある問題

- `node is not recognized`: Node.js 22 LTSをインストールし、端末を開き直してください。
- WebGL案内が出る: ブラウザを更新し、ハードウェアアクセラレーションとGPUドライバーを確認してください。
- 音が出ない: ブラウザの自動再生制限により、タイトル画面を一度クリックしてください。設定の音量も確認します。
- スマートフォンから接続できない: PCと同じWi-Fiか、WindowsファイアウォールでNode.jsを許可したか、ViteのNetwork URLを使用しているか確認します。
- 画面が重い: 設定から描画品質を「低」にします。
- 別のWebアプリが開く: 必ずゲーム専用URL `http://localhost:53173/` を開きます。`localhost:5173` は使用しません。
- ポート使用中: 既存のNode/Viteサーバーを終了するか、package.jsonとvite.config.tsのポートを同じ未使用番号へ変更します。

## 技術上の補足

味方・敵はそれぞれ `THREE.InstancedMesh` で一括描画し、ゲーム判定は軽量なXZ平面計算と空間グリッドを使用します。各兵士はHP、攻撃力、攻撃間隔、移動速度、索敵範囲、攻撃範囲、ターゲットを保持します。最大300味方 / 220敵の固定プールを再利用し、同陣営分離とターゲット分散で局所的な前線を形成します。タブ非表示時は自動停止し、画面回転・リサイズ・セーフエリアに対応します。
